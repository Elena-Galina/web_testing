# 🛒 Web shop testing 

I tested the webstore https://intern.demoshopping.ru/ functionality, including the registration, authorization, catalog, shopping cart, and product filtering/sorting modules. I applied test design techniques to cover scenarios; prepared test documentation (checklists, test cases); and created bug reports detailing reproduction steps and expected vs. actual results (<a href="https://drive.google.com/drive/u/0/folders/1WoDjzphTfo0jR8T3uz7IXO1sbawWDLj3">link</a> to requirements).
